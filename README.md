# Mech-Phys

Веб-приложение для создания сцен с механическими объектами и анализа сил. В интерфейсе можно добавлять плоскости и блоки, задавать параметры и связи между объектами.

## Запуск

В репозитории нет файла со списком зависимостей. Для используемых в приложении FastAPI, шаблонов и сессий можно установить пакеты и запустить сервер из корня проекта:

```bash
git clone https://github.com/DomiStjls/Mech-Phys.git
cd Mech-Phys
pip install fastapi uvicorn jinja2 python-multipart itsdangerous
uvicorn app.main:app --reload
```

Откройте http://127.0.0.1:8000. Команды приведены по коду, полный запуск не проверен.

## Структура

- `app/main.py` — маршруты приложения.
- `app/logic/` — объекты, сохранение сцен и анализ сил.
- `app/templates/` и `app/static/` — интерфейс.

Сцена и параметры сохраняются в создаваемой при работе папке `data/`. Проект содержит незавершённые части.
